# Student Laptop Finder

A responsive web app for browsing laptops, searching and filtering them, reading full specifications, saving favourites and comparing them side by side. Built for SW302 (User Interface Development), Assignment 2, with plain JavaScript (ES modules) and Tailwind CSS 4.

GitHub repo: https://github.com/romiiali/Laptop-finder

## Pages

| File | Purpose |
|---|---|
| `index.html` | Home page with live statistics |
| `laptops.html` | Catalogue with search, filters and sorting |
| `details.html?id=7` | Full details of one laptop |
| `favourites.html` | Saved favourites (kept in localStorage) |
| `compare.html` | Side-by-side comparison with the best values highlighted |

## Install and build

You need [Node.js](https://nodejs.org) installed.

```bash
# 1. install the packages (Tailwind CSS 4 and its plugins)
npm install

# 2. build the CSS once
npm run build

# or rebuild automatically while you edit
npm run watch
```

The build reads `src/input.css` and writes `dist/output.css`, which every page links.

## Run the app

`fetch()` does not work on pages opened directly as files, so use a local server, for example the **Live Server** extension in VS Code: right-click `index.html` and choose **Open with Live Server**.

## Features

- Laptop data loaded with `fetch()` and `async/await` in `try/catch`, with a loading skeleton and an error message
- Two themes: Performance Mode (dark, orange) and Battery Saver Mode (light, green), remembered on every page
- Favourites and comparison list saved in localStorage
- Responsive layout with a collapsing navigation menu on phones
